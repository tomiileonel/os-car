# New Feature

Description: End-to-end feature delivery.

## Steps
1. Read rules and project context.
2. product-requirements.
3. domain-architect when domain behavior changes.
4. software-architect when boundaries/infrastructure may change.
5. Implement DB/auth/backend/frontend/UI/integrations/jobs as needed.
6. qa-test.
7. accessibility-specialist for UI interaction.
8. security-review for trust boundaries.
9. performance-engineer for performance-sensitive changes.
10. code-review.
11. release-manager for production delivery.
